# Specs (SDD)

Especificações Spec-Driven Design do projeto: cada funcionalidade é
especificada aqui **antes** de ser desenvolvida, e a spec é a fonte de verdade
— se o código muda, a spec muda antes.

Ficam separadas do código e das páginas do protótipo (`docs/novo-modelo/`)
de propósito: a spec descreve o quê e o porquê; a página é uma implementação.
